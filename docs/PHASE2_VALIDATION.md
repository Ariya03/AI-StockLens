## 实现组件与 API

- `IntentPanel`：中文偏好输入、3 个明确标注的示例策略、手动配置说明；输入不会触发模拟 AI 或关键字匹配。
- `StrategyBuilder`：按指标元数据生成，提供运算符、阈值、启用/停用、建议默认与用户设置标记、定义/边界、条件校验。
- `ResultsPanel / StockCard / EvidenceDetails`：三值结果分组、逐条件阈值和状态、来源与原始字段、报告期/窗口、供应商与获取时间、计算输入、缺失/错误原因。
- `ComparisonPanel`：同快照新增、移出、未变及无法判断转移，逐股解释具体改变的条件和真实观察值。
- `Workspace`：空状态、加载、防重复操作、草稿状态、错误与过期提示、显式刷新警示和研究用途说明。
- `POST /api/screen`：保留 Phase 1 筛选行为，新增归属当前 HttpOnly 会话的服务端快照。
- `POST /api/compare`：只使用服务端原快照与原条件，拒绝客户端伪造快照/比较基准；不调用金融数据工具。
- 内存会话：绝对有效期 15 分钟，总上限 100、每会话 3、单快照 128 KiB；请求体 16 KiB；来源校验及并发取数限制。过期/不可用明确返回，不自动换数据。
