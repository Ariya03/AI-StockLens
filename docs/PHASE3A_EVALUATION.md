# Phase 3A：Qwen 2.5 3B 意图解析评估

**结论：NO-GO。不建议将当前本机 `qwen2.5:3b` 直接接入产品意图解析。** 一次针对性改进后，本批 30 条用例没有关键错误逃逸，但完整正确率仅 53.3%，明确请求可用率仅 58.3%；达不到受约束原型的预设门槛。建议用更强的中文指令模型复验，再决定 Phase 3B。当前工作台继续维持诚实的手动配置模式。

评估日期：2026-10-15，北京时间。已先检查 PRD V1.1、指标注册表、规则 schema/校验与 Phase 2 工作台。未修改上述文件、金融口径或确定性引擎，未增加金融指标/股票，也未新增 UI 或模型 API 路由。

## 解析契约与职责边界

模型仅可输出 `outcome / conditions / issues`，没有股票、行情、建议、预测、置信度或自由叙述字段。

- `READY`：明确、支持、相容，条件非空且没有待处理问题；通过全部校验后才有候选可执行规则，未来仍须用户确认。
- `CLARIFY`：模糊、报告期/窗口不明确、冲突或注入；可保留有依据的候选条件，但**整个请求的可执行规则为空**。
- `UNSUPPORTED`：未支持指标、口径、OR、交易或保证收益等；可以保留支持部分用于展示，但**不能部分执行或默默删掉不支持意图**。

每个 condition 仅有指标 ID、运算符、显式阈值和原文连续引用。程序核对引用，并在原文中计算 UTF-16 的 `[start,end)` 证据跨度（包括 emoji）；不让模型自行编造字符位置。规则的单位、年报报告期和窗口来自原有注册表，origin 固定为 user；模型不提供数值默认值，不自动补 `PE > 0`。

本次显式政策：裸 PE/市盈率使用注册表唯一支持的 TTM 语义，不改变阈值；ROE 必须确认 2025 年报，波动率必须确认 60 个交易日日收益率口径。不明示这两项时不能静默套用。此政策写入提示词及用例。

确定性检查包括严格字段白名单、类型/有限值、引用逐字匹配、数值证据、既有单条/AND 条件校验；v2 加入报告期、窗口、局部指标/比较方向与完整输入的保守拒绝门控。**门控只拒绝模型提议，不生成、修正或替换条件，也不通过关键词伪装成 LLM。** 无效模型输出返回 validation.accepted=false 和空可执行数组，不自动改写成一个伪造的成功解析。

中文数字“二十”在当前数值/方向门控中不能通过，按失败记录，不自动转成模型没有给出的备用规则。重复引文的首次匹配位置和复杂省略/否定等上下文仍是限制，不能声称一般自然语言都已被确定性证明。

## 预设判定标准

在首轮调用之前写入 metadata：

- GO：关键错误逃逸为 0，完整正确率 ≥95%，明确请求可用率 ≥90%，p95 ≤20 秒。
- CONDITIONAL GO：关键错误逃逸为 0，完整正确率 ≥80%，明确请求可用率 ≥75%，且强制人工确认及拒绝门控。
- NO-GO：有关键错误逃逸，或低于 CONDITIONAL GO 的质量门槛。

“完整正确”要求解析 outcome、全部条件的指标/运算符/阈值均与独立预期一致，且校验通过；缺条件、证据改写、错误分类和过度澄清均算失败。预期答案没有作为模型输入。原始关键错误提议与校验后的关键错误逃逸分别计数，不能用拒绝所有输出来冒充高质量。

| 指标 | v1 基线 | v2 一次改进 |
|---|---:|---:|
| 实际调用 | 30 | 30 |
| JSON 语法有效 | 30/30 | 30/30 |
| 校验接受（不代表语义正确） | 13/30 | 22/30 |
| 完整正确 | 6/30，20% | 16/30，53.3% |
| 明确请求正确可用 | 5/12，41.7% | 7/12，58.3% |
| 原始关键错误提议用例数 | 14 | 6 |
| 关键错误逃逸用例数 | 5 | 0 |
| p50 / p95 请求耗时 | 2.287 / 5.051 秒 | 2.027 / 4.512 秒 |
| 最大耗时 | 11.499 秒 | 4.592 秒 |
| 结论 | NO-GO | **NO-GO** |

逃逸指审计发现校验返回的可执行规则仍不符合原意；**本阶段没有把任何模型规则实际送入金融筛选**。首轮 5 个逃逸用例为 C08、A16、A17、U21、U22：错误否定边界、擅自套用年报/窗口、年化口径误用、OR 被当成 AND。

只做了一次针对性改进：针对 v1 的证据改写、无数字强加条件、否定方向、范围不明确等失败，加入逐字复制的格式示例，并加强拒绝式方向/数值/口径核对，随后完整重跑同一批 30 条。没有继续调参或循环优化来挑选好结果。v1 保存为历史基线，适配器与校验器默认使用 v2。

## 关键失败证据

| 用例 | 原意 / 预期 | v2 原始模型行为 | 处理 |
|---|---|---|---|
| C07 | `PE至少8倍，同时小于20倍` → gte 8、lt 20 | 把小于20变成 lte 20，且改写引用 | 关键边界错误，拒绝 |
| C08 | `不要PE大于20倍` → lte 20 | 输出 lt 20，误排除等于20的边界 | 关键方向/边界错误，拒绝 |
| U23 | PE≤20 且股息率≥3，股息率不支持 | 把股息率3映射为年报ROE≥3 | 关键 unsupported substitution，拒绝 |
| X26 | 注入要求跳过规则、伪造 READY | 添加 PE<5、PE≤17.3、ROE≥10；17.3 来自提示词格式示例而非用户 | 关键默认/示例污染，拒绝 |
| C06 | 三条明示数值条件 | 数值正确但把原文逗号/子句改成句号 | 引用不是逐字原文，拒绝；属于可用性失败 |
| U18–U21 | 股息率、增长率、2026年中报、年化波动率不支持 | 多数被分类为 CLARIFY，询问用户是否已明确刚才说过的口径 | 未执行，但错误边界判断；完整评估失败 |
| C29 | 明确2025年报ROE<0 | 仍追问是否使用2025年报 | 过度澄清，降低明确请求可用率 |

v2 的零逃逸仅覆盖本批有限合成样本，不证明提示注入、复合逻辑、否定范围、重复引文或别名都安全。约束格式与低温度均没有消除原始语义错误。

## 下一步建议

停在 Phase 3A。当前 3B 的正确前置动作是评估更强中文指令模型，而不是把 3B UI 包在不可靠解析器外面：先冻结本次用例，另设未参与提示词设计的留出集，覆盖多轮修正、省略主语、组合否定、OR/NOT、事实引述、单位/报告期和注入；每次新模型都比较原始与拒绝后的错误，并验证重复运行稳定性。

门控仍需加强完整输入覆盖与局部语义证明，减少误拒绝并避免遗漏否定上下文。未来所有 READY 都必须让用户确认；参考默认值只能由注册表/应用显式提出并标为建议，不能伪装成原文阈值。任何拒绝/超时都应显示解析不可用或澄清，保留诚实的手动编辑入口，不能静默用关键词补一个成功结果。
