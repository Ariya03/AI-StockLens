# AI StockLens｜自然语言智能选股与策略解释器

将投资偏好转为可审阅、可修改的选股条件，用真实金融数据解释股票为什么入选、排除或无法判断。面向同花顺 AI Native 产品经理招聘挑战，优先展示「明确条件 → 真实筛选 → 查看依据 → 同快照比较」的完整研究流程。

**仅为筛选研究工具，不构成投资建议。** 不提供收益预测、买卖推荐或自动交易。

## 推荐操作路径

1. 打开工作区，点击明确标注的「加载示例策略」，或直接手动设置条件。默认模式也可输入明确数值偏好并点击「解析并澄清条件」；这是**程序化澄清，不是生成式大模型**。
2. 审阅提案后显式确认，再在条件编辑器修改运算符、阈值和启用状态。示例建议值与用户设置有不同标记；空值、矛盾条件和无有效条件会阻止执行。
3. 点击「获取真实数据并筛选」，查看「已入选 / 已排除 / 无法判断」。展开每只股票的依据，核对真实数值、阈值、条件状态、原始字段、来源、报告期及时间。
4. 修改条件，点击「使用原快照比较条件」，查看新增入选、移出与未变股票的解释。比较复用原始数据和原始策略，**不追加扶摇请求**。
5. 可选择「保存当前条件」写入本机浏览器并下载 JSON；「读取已保存条件」只读取该浏览器保存的草稿，不导入下载文件、不恢复服务器快照、不自动筛选。此新增功能有一项组件测试失败，尚待浏览器复验。

以上为本地操作路径，公网核心任务尚未通过验收。自然语言处理不自动执行筛选。无法理解的表达、不支持的指标或未通过校验的输出不能成为可确认的执行条件；本地手动流程独立可用。

## 本地启动

需要 **Node.js 24.x** 和 npm。依赖版本以 [package-lock.json](package-lock.json) 为准。

```sh
npm ci
```

首次使用时将 [`.env.example`](.env.example) 复制为 `.env.local`，在本机编辑并填写有效的 `FUYAO_API_KEY`。**已有 `.env.local` 请保留，不覆盖。** 缺少密钥时无法取得有效真实数据；应用不会生成替代金融数据。

```sh
npm run dev
```

打开 [本地工作区](http://localhost:3000)。生产模式：

```sh
npm run build
npm run start
```

本地启动无需 Ollama、数据库或付费云 API。测试运行方法见 TESTING。

## 环境变量

| 变量 | 用途与配置要求 |
|---|---|
| `FUYAO_API_KEY` | 扶摇密钥，仅服务端读取；不要添加 `NEXT_PUBLIC_` 前缀或写入源码、命令参数、截图。 |
| `STOCKLENS_PUBLIC_ORIGIN` | 公网必须为实际规范 HTTPS origin，无路径、参数或末尾斜线。本机开发应**不定义**，不是定义为空；空值也会触发公开配置检查。 |
| `STOCKLENS_PUBLIC_DEMO` | 设为 `1` 显式启用公网配置检查；`RENDER` / `VERCEL` 环境或定义公开 origin 也会触发检查。 |
| `STOCKLENS_MAX_UPSTREAM_CALLS_24H` | 单进程滚动 24 小时调用预扣预算，默认 `140`，每次完整筛选预扣 `7`。不是供应商账户额度或账单上限，重启后重置。 |
| `STOCKLENS_LOCAL_AI` | 仅受监督本机实验设为 `1`；公开环境强制关闭本地 Ollama 模式。默认使用明确标注的程序化澄清。 |

密钥不发送给浏览器或模型。来源检查依赖显式配置，忽略任意 forwarded headers；公网 Cookie 使用 Secure。不要关闭 TLS 校验。`.env.local` 和生成目录有忽略规则，但发布前仍需检查 Git 暂存内容。

## 数据来源与确定性口径

扶摇 HTTPS API `fuyao.aicubes.cn` 提供估值、财务和历史行情；接口、字段与错误处理在 [lib/fuyao/](lib/fuyao/)。真实验证记录见 TESTING，文档中的历史数值不是当前行情。

演示股票池固定为 **贵州茅台 600519.SH、平安银行 000001.SZ、同花顺 300033.SZ**，不代表全 A 股市场。

| 指标 | 执行口径 |
|---|---|
| PE TTM | 供应商 `pe_ttm`，单位倍；零和负值保留，要排除需显式设置 PE > 0。 |
| 2025 年报 ROE | `report=2025-4` 的加权平均净资产收益率，百分数原值；不擅自切换报告期、不年化。 |
| 60 日日收益率波动率 | 最近 61 个前复权收盘价形成 60 个简单日收益率，样本标准差 ×100，分母 59；不年化。 |

指标注册表规定单位、报告期/窗口与约束。条件支持 `gt/gte/lt/lte/eq`，只做 **AND**：任一 FAIL → 排除；否则任一 UNKNOWN → 无法判断；全部 PASS → 入选。缺失、无效或过期数据明确标记，不补零、不虚构。解释来自引擎与数据证据，不由模型编造。

## AI 的角色

LLM 只参与本机「意图 → 候选条件」实验，不能决定指标定义、默认阈值、股票结果或金融事实。输出须经过 schema、原文证据、数值/运算符、指标及口径校验，再由用户确认。

本地 Ollama `qwen2.5:3b` 的 Phase 3A 结论为 **NO-GO**。后续证据复制修复解决了两个 PE 输入，但完整真实回归仅 **10/16**；不作为公网默认 AI 能力。程序化澄清是独立的受限规则实现，不是 Qwen 的能力，也不是模型失败后的静默替代。工具分工与人工修正详见 AI_USAGE。

## 部署边界与未做事项

[render.yaml](render.yaml) 保留为免费 Node 单实例配置参考，并非当前 Vercel 部署配置或验收证明。当前公网状态见上文；云端扶摇出站及 HTTPS 会话仍未完成验收。只考虑零额外支出，不保证免费服务长期可用。

快照存放在**单进程内存**，有效期 15 分钟，有限容量。休眠、重启或切换实例后可能丢失；缺失/过期返回明确错误，需用户主动重新取数。不能直接假设多实例或 Serverless 跨请求共享快照。`/api/health` 只检查进程和配置，不调用扶摇，不证明上游可用。

未做全市场扫描、更多指标、历史回测、账号/云端策略同步、监控任务、预测、自动交易、iFinD 接入或可靠云端 LLM。财报披露日、交易日历及复权独立核验仍有限；扶摇公开展示授权与实际额度须确认。仍需处理已记录的两项测试失败，并完成最终公网验收后再宣称比赛交付齐全。
